# Evolving Rule-World | Four independent nights (proposed)

## World
Generate finite symbolic state machines with an independent exact interpreter. Domain A modular arithmetic (mod 17, explicit variable bindings, compositions of primitive ops); Domain B permutations (3–8 symbols, swaps and composition); C cross-domain compositions, D unknown/relabelled rules or contradictory evidence (future if feasible). Each session has new ephemeral bindings, persistent rule semantics and queries; held-out compositions, depth and consistent symbol relabelings test transfer. Do not confuse arbitrary new mappings with already learned rules. Explicit domain tag initially; no answer-bearing features. Pretrain shared interface on separate development corpus, freeze before target sequence. Rule generator and scorer independently checked with enumerated cases. Split by rule/program families and seeds before generation (train/calibration/holdout disjoint; no holdout queries or labels to sleep/patch selection). Holdout scored once per frozen arm; use separate development validation for tuning.

## Nights
a — The First Dream. Can a structured compilation replace deeper recurrence on unseen inputs? Human derives W^K and residual correction by hand. Exact permutation-matrix positive control, then if feasible learned one-expert recurrent baseline. Compare shallow/deep/compiled/norm-rank-matched random/matched gradient. Primary metric held-out exact-match (or exact operator equality for control); separate exact supplied-program compilation from inferred program learning. Suggested learned gate: teacher at least 80% held-out, student within 5 percentage points and >=50% fewer executed loops; report FLOPs/latency, rank and all arms. If learned model unready, exact instrument result only, no neural learning claim.
b — Light Sleep. Does an offline associative writer retain session information after eviction? Fixed independently qualified tiny instrument. Compare KV retained, eviction empty, M-only, S-only, fast adapter-only, combined, and matched one-pass writer. Fresh query set, changed bindings, no future-query access. Suggested gate: within 5 pp of retained KV and better than empty by >=10 pp at declared memory bound; report each arm. Separate rank-r bridge from S retrieval.
c — The Two Clocks. Does offline depth substitute for online depth on novel multi-step cases? Compare K=1,2,4,6 and N=0,1,2,4,8; if time limited preregister 2x2 (K=2,6; N=1,8). Compare no-sleep, online-only, matched total compute; quantify minimum K for fixed accuracy, actual operations and lifecycle cost. Choose primary contrast before execution; illustrative target K=2,N=8 within 5 pp of K=6,N=1 at comparable total compute for declared number Q of queries. N=0 is a control, not automatically equivalent to no memory. Report failure if no tradeoff.
d — Deep Sleep / The Four Experts. Does a validated durable patch acquire a new rule while retaining old capability after fast reset? Use hard-routed two-domain isolation first, then mixed route stress if feasible. Baselines no edit, adapter merge, matched gradient/replay, structured candidate; test fresh sessions, no stale bindings, domain A bitwise logits on fixed deterministic backend when all dependencies fixed, parameter and optimizer-state hashes, B acquisition (suggested +10 pp vs pre-patch, compare matched arms), rollback and invalid patch rejection. A simple isolated pass is structural non-interference, not general continual learning. Dreaming curriculum and learned selection are stretch/future, not required for d. No full integration claim without executing all relevant mechanisms.

Each night must independently freeze its actual thresholds, seeds (suggest >=3 paired seeds if affordable), sizes, hardware, time cap, split and primary metric before seeing results. Proposed thresholds above are reviewable design defaults, not execution freeze. A small fixed positive control is a valid instrument outcome but not a substitute for learned evidence. Any missed night has no debt; no re-opening closed evidence. Use ordinary root night protocol and I/H/C/D assistance record.

## Seven measures
1. Centered activation covariance participation ratio (tr C)^2/tr(C^2) across inputs at each k; report zero variance separately, relevant separability and held-out task accuracy, no arbitrary universal rank gate.
2. KV ablation exact-match and difference, memory bytes across all tiers, including M and replay.
3. Retention old-domain logits/checkpoint hashes plus accuracy and interference after mixed routes.
4. Depth crystallization: shallow post-patch versus deep teacher on novel programs, actual executed K and compute.
5. Generalization: interpolation, extrapolation, relabelled/compositional transfer and changed session bindings separately.
6. Compiler advantage: matched calibration observations, candidate budget, writable support/rank, compute; report all conditions, not just winner.
7. Lifecycle efficiency: sleep cost plus Q * awake cost, at matched accuracy and fixed query workload; report latency, bytes, operations and break-even. Include failed candidate and rehearsal costs.

Record planned vs scored denominators, malformed/failed outputs, per-seed paired results, uncertainty, checkpoint and code/data hashes. Frozen external evaluator and immutable test fixtures; use CPU/Colab synthetic only.
